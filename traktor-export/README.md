# Traktor History exporter

## how to use

run executable normally to automatically find all `.nml` files in traktor history folders  
and generate / update tracklsits for all

drag `.nml` files on the executable to convert just those

## download [traktor-export.exe](https://github.com/NikkyAI/setlist-export/releases/download/nightly/traktor-export.exe)
