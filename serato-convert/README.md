# Serato setlist converter

## how to use

Export the session as csv (or txt)

the exported file will be in `%HOMEPATH%\Music\_Serato_\History Export`

drag the csv or txt file onto the `exe` to convert

## download [serato-convert.exe](https://github.com/NikkyAI/setlist-export/releases/download/nightly/serato-convert.exe)
